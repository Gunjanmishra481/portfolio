The
problem

Navigation apps optimise for time. None of them tell you what a route costs in emissions, so the greener choice stays invisible.

What I built

01

Estimates each route's CO₂ emissions using DEFRA/EEA emission factors.

02

Ranks routes with a multi-criteria weighted-sum model.

03

Surfaces the greener option right next to the fastest one.

Built with

SwiftUI · Supabase

Outcome

Lower-emission routes become a one-tap choice instead of guesswork.
